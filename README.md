# 🎬 FlirtUA Ads — рекламные ролики для TikTok на fal.ai

Отдельное приложение: открываете свой адрес на Railway, входите по паролю и делаете вертикальные рекламные ролики
для бота знакомств FlirtUA — для TikTok, Instagram Reels и YouTube Shorts.

## Как пользоваться

1. Выберите **формат**: POV-история, проблема → решение, 3 причины, земляки, кава сьогодні, обычные приложения vs FlirtUA, мини-история.
   Затем **страну**, **кому показываем**, **голос** и **кадры**: фото с движением или оживление через Kling.
2. **«✨ Придумать сценарий»** — нейросеть пишет сценарий на украинском: крючок, 4 сцены, призыв найти бота, подпись с хэштегами. Всё можно поправить.
3. **«🎬 Сделать видео»** — рисуются кадры (gpt-image-2), записывается голос (ElevenLabs) и музыка (CassetteAI),
   ролик 1080×1920 MP4 собирается прямо в браузере. Последний кадр — FlirtUA и @бот.
4. **Скачать MP4** и **скопировать подпись**. Неудачный кадр — «↻ Заново» под ним и «Пересобрать»: голос и музыка останутся.

## Голос — ElevenLabs

С ключом `ELEVENLABS_API_KEY` в приложении появляется выбор голоса:
- любой голос из вашего аккаунта ElevenLabs, украинские — сверху с 🇺🇦, кнопка ▶︎ для прослушивания;
- нативные украинские голоса: [Voice Library → Ukrainian](https://elevenlabs.io/app/voice-library?language=uk) → «Add to my voices», затем «обновить список» в приложении;
- модель **Eleven v3** (самая живая: нейросеть расставляет эмоции вроде `[excited]`, `[laughs]`) или **Multilingual v2** (ровнее);
- подача: эмоционально / естественно / ровно;
- вся озвучка записывается **одним дублем** — интонация цельная, а сцены переключаются точно по началу следующей фразы.

Собирайте ролики в **Chrome или Edge на Windows/Mac** — там звук AAC, TikTok принимает без проблем.

Стоимость в fal.ai: ~$0.25 за ролик с фото, ~$1.7 с оживлением Kling. Сценарий — меньше цента.

## Запуск на Railway

1. Railway → **New Project** (или в проекте бота: **+ New → GitHub Repo**) → выберите этот репозиторий.
2. **Variables**:

| Переменная | Что это |
|---|---|
| `FAL_KEY` | ключ fal.ai (можно тот же, что в AdsVideoMaker) |
| `APP_PASSWORD` | пароль для входа в приложение |
| `ELEVENLABS_API_KEY` | **рекомендуется** — ключ ElevenLabs (elevenlabs.io → Profile → API Keys). Голос напрямую из ElevenLabs: любой голос вашего аккаунта, модель v3 с эмоциями, вся озвучка одним дублем. Без ключа — ElevenLabs через fal.ai, два стандартных голоса |
| `BOT_USERNAME` | (по желанию) имя бота без @, по умолчанию `FlirtUa_bot` |
| `COUNTRIES` | (по желанию) страны через запятую, по умолчанию «Іспанія, Польща, Німеччина, Чехія, Італія» |
| `FIREBASE_JSON` | (по желанию) тот же ключ Firebase, что у бота — тогда в рекламе будут **настоящие** цифры анкет. Без него цифры не упоминаются |

3. **Settings → Networking → Generate Domain** — это и есть адрес приложения.
4. Проверка: `https://АДРЕС/health` — `falKey: true`, `password: true`.

## Безопасность

Ключ fal.ai хранится только на сервере. Страница обращается к fal.ai через прокси `/fal`, который работает
лишь после входа по паролю и только с нужными моделями (any-llm, gpt-image-2, kling-video, elevenlabs, CassetteAI).

## Правила рекламы

Люди в кадре сгенерированы нейросетью — при запуске рекламы в TikTok отметьте «AI-generated content».
Реклама знакомств в TikTok разрешена только для 18+ и с ограничениями по странам — проверьте правила рекламного кабинета.
